# RG 업무포털 — 시연 · 검증 안내

직접 만든 RG 그리드 엔진으로 지은 ERP·그룹웨어 화면 시연입니다(빌드 결과물만 있습니다. 소스는 별도 비공개 저장소).

- **열기**: https://jkshin0009-art.github.io/rg-portal-demo/
- **결함 보고**: [이슈 새로 열기](https://github.com/jkshin0009-art/rg-portal-demo/issues/new/choose) → «결함 보고» 양식
- 입력한 데이터는 보는 사람 브라우저에만 저장됩니다(오른쪽 위 «샘플 초기화»로 되돌림).

# 중점 점검 목록

## 1순위 — 우리가 자동으로 확인하지 못한 것(사람 손이 필요)

| # | 화면 | 해 볼 것 |
|---|---|---|
| 1-1 | 실험실 › 그리드 엔진 | **열 너비 끌기**: 머리 경계를 잡고 좌우로 끌기, 아주 느리게/빠르게, 고정 열 경계, 경계 두 번 클릭(자동 맞춤) |
| 1-2 | 거래처·품목 | **한글 입력**: 칸에 바로 한글 타자 → 조합 중 Enter·Tab·화살표·Esc, 빠르게 연타, 받침 있는 글자로 끝내기 |
| 1-3 | 거래처·수주 | **엑셀에서 복사해 붙여넣기**: 여러 행·여러 열, 빈 칸 섞인 범위, 숫자에 쉼표·날짜 형식 다양 |
| 1-4 | 아무 화면 | **브라우저별**: Chrome · Edge · Firefox · Safari(가능하면), 화면 확대 125%·150%, 노트북 터치패드 스크롤 |
| 1-5 | 실험실 › 성능 측정 | 10만 행 측정 돌리기 → 결과 숫자 캡처. 측정 중 화면이 멈추는지 |

## 2순위 — 업무에서 매일 쓰는 흐름

| # | 화면 | 해 볼 것 |
|---|---|---|
| 2-1 | 거래처 관리 | 행 추가 → 필수 칸 비운 채 저장(그 칸으로 가며 안내가 나와야) → 채우고 저장 → 새로고침 뒤 남아 있나 → 수정·삭제 → 저장 |
| 2-2 | 거래처 관리 | 편집 중 다른 행 클릭 / 그리드 밖 클릭 / Esc 두 번 → 값이 확정·취소되는 것이 자연스러운가 |
| 2-3 | 수주 관리 | 위 목록 행을 바꿀 때 아래 상세가 따라오나, 상세 편집 후 위 행 이동 시 잃는 값이 없나 |
| 2-4 | 재고 현황 | 묶기(그룹) 펼치기·접기, 그룹 합계·바닥 합계 숫자가 맞나, 묶은 채 정렬·필터 |
| 2-5 | 아무 그리드 | 머리 필터 단추(엑셀식 목록): 여러 값 고르기·검색·전체 해제, 한글 초성 검색(예: «ㄱㅅ»), 필터 후 건수·합계 |
| 2-6 | 아무 그리드 | 정렬: 머리 클릭 오름/내림/해제, Ctrl(또는 Shift)+클릭 여러 열 정렬 순번 표시 |
| 2-7 | 아무 그리드 | 선택: 끌어서 범위, Shift+클릭, Ctrl+클릭 여러 범위, Ctrl+A, Delete 로 지우기, Ctrl+Z 되돌리기 |
| 2-8 | 아무 그리드 | 엑셀 내려받기 → **엑셀로 열어서** 숫자가 숫자로(합계 가능), 날짜가 날짜로, 묶음·합계 줄·머리 병합이 깨지지 않나 |
| 2-9 | 전자결재·공지·일정·조직도 | 목록 조회·검색·상세 열기가 막히지 않나 |

## 3순위 — 모양·읽기 쉬움

| # | 해 볼 것 |
|---|---|
| 3-1 | 숫자 칸 오른쪽 정렬·천 단위 쉼표, 음수·0·빈 값 표시 |
| 3-2 | 글꼴(Pretendard)이 화면·그리드에 같게 나오나, 잘린 글에 마우스를 올리면 도움말 |
| 3-3 | 좁은 창(1280px 이하)·세로 모니터에서 가로 스크롤·고정 열 |
| 3-4 | 행 강조(마우스 올림·현재 행)·선택 색이 업무 화면으로 보기 편한가 |
| 3-5 | 트리 엔진·렌더러 견본·행 끌어 옮기기 실험실 화면이 깨지지 않나 |

## 알려진 한계(보고하지 않아도 됨 — 이미 안다)

- 100만 행에서 정렬·묶기는 0.6~1초 화면이 멈춘다(업무 규모 수만 행은 문제없음).
- 입력한 데이터는 보는 사람 브라우저에만 저장된다(오른쪽 위 «샘플 초기화»로 되돌림). 서버 저장은 없다.
- 숫자 칸 오른쪽 정렬·앱 글꼴은 실물 RealGrid 와 **일부러** 다르게 했다.
